## ✦ 01 / 从一次生成，到持续创作

提示词只是起点。真正的创作工作，还包括试验方向、组织批量任务，以及找回值得再次使用的素材。

### 为什么需要它

当想法留在聊天里，生成进度留在另一个工具里，结果又散落在下载文件夹，下一轮创作往往要重新找上下文。100xSPEED 将这些工作放进创意区、任务区和资产库，让一次尝试留下可继续处理的记录。

### 谁会用到

需要持续制作图片、视频素材的内容创作者、跨境电商内容团队，以及负责整理和交付素材的人。尤其适合围绕同一商品或主题，比较多个视觉方向的工作。

### 读完后，你能判断什么

知道创意如何进入任务、生成结果如何归档，以及自己的工作更适合独立工作台还是 Agent 对话。产品入口为 100xspeed.app；具体模型与可用服务以实际接入为准。

## ✦ 02 / 三个区域，一条创作流程

当前 Web 产品由创意区、任务区与资产库组成。三者分别负责准备、执行和保留结果。

![100xSPEED 工作流程与角色图解](overview.png)

### 01 / 创意区：先把方向试清楚

在创意区编写提示词，直接生成图片或视频；使用魔法棒提取 {变量}，围绕场景、人物或表达方式展开单点试验。先观察一个方向是否值得继续，再决定是否进入批量任务，避免还没理解效果就扩大生成。

### 02 / 任务区：把选中的卡片变成批次

将已生成卡片推送到任务区，展开并执行批量生成任务，观察处理进度。这里解决的是“哪些任务正在执行、哪些结果需要处理”，让执行过程与创意试验各有清楚的位置。

### 03 / 资产库：让结果可找回、可流转

统一查看、筛选和管理生成产物，按批次归档并用于后续工作。归档不只是保存图片：团队需要保留结果所属的创意方向与任务上下文，方便复用、比较和交付。

### 使用时怎样分工

> 创意区决定尝试什么，任务区负责组织执行，资产库承接结果。质量判断仍由人完成：生成结束不等于素材已经适合发布。早期无限画布已退役，本册介绍当前 Web 工作台。

## ✦ 03 / 案例：为一款保温杯准备素材

以下是示例工作方案，用来说明产品如何进入真实创作流程；不是已完成的客户案例，也不包含效果承诺。

### 任务简报

> 对象：一款无品牌标识的保温杯。目标：比较通勤、办公、户外三个视觉方向。准备：可使用的商品参考图、目标画幅、必须保留的外观特征，以及需要避开的表达。先明确素材用途，再安排生成。

### 01 / 先试一个方向

在创意区先做通勤方向，检查杯身、杯盖、使用场景与构图是否符合简报。记录需要修改的词，避免把一个不稳定的提示词直接扩成一批结果。

### 02 / 再组织可比较的任务

选定值得继续的卡片，把场景作为变量准备不同方向。比较时尽量保持主体要求和画幅一致，这样更容易判断差异来自场景还是生成条件。

### 03 / 查看结果，留下选择理由

在任务区跟进执行，在资产库筛选结果。建议交付时附上“保留、返修、舍弃”的理由；需要返修的结果回到下一轮创意准备，不把全部产物直接当作可用素材。

### 建议交付与检查

一组人工筛选后的图片或视频、对应创意方向和下一轮修改点。检查主体一致性、构图与画幅、明显生成错误，以及是否符合既定用途；不以生成数量代替质量。

## ✦ 04 / 怎样开始，怎样与生态配合

先完成一个小任务，再决定要扩展哪部分流程。下面是使用建议，不是额外的产品功能承诺。

### 准备一份可执行的简报

至少说清对象、受众、用途、参考素材和不能改变的约束。只给一句“做得好看”会让结果很难比较；把具体要求写出来，也方便他人继续处理同一个任务。

### 用小批次验证完整路径

先走一次创意生成、推送任务、取得结果与归档的完整流程。确认任务状态和素材位置能被理解，再扩大任务数量。实际模型、输入组合和服务可用性按当前账户与产品为准。

### SPEED、MCP 与 SKILL 各管什么

SPEED 提供面向人的创作工作台；MCP 把生成工具带进 Agent 对话；SKILL 提供分析、改编与提示词方法。可以先选最符合自己习惯的入口，不需要把所有产品一起接上才开始。

### API 与 ROUTE 在什么位置

API 关注生成请求、任务与结果；ROUTE 关注线路目录和运行依据。本册描述职责关系，各产品独立演进，不把分工图当成所有模块已经完成生产联调的证明。

### 当前开放与了解方式

> 通过官网了解产品。对具体模型、账户权限和服务条件有疑问时，按产品当前说明确认。希望参与工程建设的人，经现有联系人确定任务与访问范围后再进入私有工程。

## ✦ 05 / 可以从哪些工作参与

下面是可用于讨论的合作任务示例。它们帮助把“想加入”变成具体交付，不代表已经发布招聘岗位或承诺资源。

### 任务 A / 创作流程体验

围绕一个合成商品简报，走完创意区、任务区、资产库。交付按步骤记录的体验报告：在哪一步不知道下一步怎么做、哪个状态含义不清、结果怎样找到。验收时能按相同步骤复现，并区分理解问题与真实缺陷。

### 任务 B / 批量任务可靠性

选定一个已获准的测试场景，观察任务提交、处理中、成功与失败时的信息。交付状态清单、异常复现条件和期望反馈。重点是让用户知道任务在哪里、是否需要重试、哪些结果已完成；不以虚构压力测试数字充数。

### 任务 C / 素材检索与交付

用允许公开或合成的素材，验证按批次找回结果、筛选与交付的路径。交付一份整理方法及几个可复现的查找任务；以另一个人能否正确找到目标素材来判断说明是否有效。

### 开始协作前对齐三件事

先说明你的经历和想改善的环节；再一起确认任务范围、交付物与检查方式；最后获得必要的邀请与素材权限。公开资料用于理解方向，内部业务数据不会随介绍仓公开。

## ✦ 06 / 常见问题与下一步

选择适合自己的入口，比一次接入所有工具更重要。

### 它与单次生图工具有什么不同？

这里关注生成前后的连续工作：创意准备、任务组织、结果查找与再次使用。是否适合你，取决于这些环节是否已经成为日常负担，而不是单看一次生成的效果。

### 是否仍有无限画布？

当前介绍的是创意区、任务区和资产库组成的 Web 工作台。早期无限画布已退役，历史截图或申请材料中的画布不应被理解为当前可用功能。

### 能直接获得可以发布的广告吗？

生成产物还需要人工检查、筛选与后续制作。产品帮助组织创作和生成过程，不自动完成商业判断，也不承诺点击率、销量或投放结果。

### 必须先接入其他 100x 产品吗？

先按官网当前流程使用 SPEED。MCP、SKILL、API 与 ROUTE 用于解释不同工作入口和职责，具体组合是否可用需要按实际服务确认。

### 建议的第一次尝试

准备一份小而明确的素材简报，选一个方向，走完生成、检查与归档，再根据体验决定下一步。希望参与建设时，带上这次过程中的一个具体问题。
