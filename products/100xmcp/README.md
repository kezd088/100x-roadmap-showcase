## 适合谁，解决什么

希望在 Codex 工作过程中完成视觉素材生成的人。

对话里的需求和外部生成工具割裂，预算、任务状态与下载结果需要反复切换处理。

## 可以怎样用

### 发现能力

检查连接，了解当前可用的模型能力。

### 报价与预算

生成前查看报价，确认预算上限后提交。

### 完成与下载

查询任务状态，取得结果并下载到工作目录。

## 一个具体场景

在 Codex 中提出“为保温杯制作一张简洁场景图，先报价”。先检查可用能力，了解报价，再确认预算并提交。完成后，把素材放到当前工作目录继续使用。

*这是帮助理解产品用途的概念案例。*

安装客户端并获得服务接入 → 描述素材需求，先查报价 → 确认预算后提交任务 → 查询结果并下载素材。

## 你会得到什么

工作目录中的生成素材，以及可继续追踪的任务结果。

## 在生态中的位置

MCP 让 Agent 连接工具；SKILL 让 Agent 知道如何组织工作；SPEED 提供独立工作台体验。三者协同互补。
